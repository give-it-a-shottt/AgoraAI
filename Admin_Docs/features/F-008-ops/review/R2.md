## 체크 항목별 근거
- cron 인증 → _check_secret(bytes compare_digest, 비밀값 비면 503, 접두사 대소문자 일치), 운영은 CRON_SECRET 없으면 기동 안 함 → 문제없음
- 헤더 처리 → max_length 512, CORS allow_headers에 Authorization 없음 → 문제없음
- CDN 캐시 → Cache-Control 없음, rewrites → 캐시 안 됨
- 비밀값 로그 → main.py 오류 로그는 method·path만 → 문제없음
- 남용·비용 → 비밀값 가진 호출자만, 새도 하루 1건 상한, 주제는 코드 상수 → 문제없음 (Q-005 임시 처리와 관련)
- 멱등성·경합 → UPDATE … WHERE used < limit로 하나만 → 이중 생성 없음, 실패 미반환은 지적 1
- 에러 응답 → 일반 문구만 → 문제없음
- SQL 인젝션 → 바인딩·상수 IN → 문제없음
- 승격 쿼리 성능 → 하루 1회, 인덱스 사용 가능, PK 함수 종속 → 문제없음
- 무거운 작업 → 생성은 BackgroundTasks → 의도대로
- 프론트 오프라인 폴링 → generating일 때만 3초, 재시도 2회 → 과도한 호출 없음, 표시 조건은 지적 2
- XSS·공개 환경변수 → 없음
- 민감 정보 → 테스트용 더미 비밀값만
