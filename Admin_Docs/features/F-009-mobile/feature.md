무엇을: 640px 미만에서 Figma 모바일 화면(0:1 Screens)처럼 보이게 맞췄다. 홈 말고는 위쪽이 "뒤로 + 제목" 줄(Sub GNB)로 바뀌고, 주 버튼은 화면 아래 고정 막대에 둔다.

## 설계 의도 (AI 대리 작성 — 사용자 위임, 출처: agora-design.md §6·§7, Figma 0:1 Screens)
- 이 기능이 해결하는 문제: 휴대폰에서도 한 손으로 보고 누를 수 있는 화면.
- 완료 기준: 640 미만에서 ① 홈 GNB는 로고 + [+ 만들기] ② 홈·승부 예측·무대·결과·만들기가 Figma MO 화면과 같은 배치 ③ 하위 화면은 Sub GNB, 주 버튼은 Bottom Button Bar, 푸터 없음
- 화면: Layout(라우트 표시 moSub), GNB, 홈 TodayCard·목록 머리, 승부 예측·무대·결과·만들기, 푸터
- API·데이터: 없음(화면만)

## 결과 (AI 작성 — 구현 후)
- 바뀐 파일: app/router.tsx(라우트 handle moSub), app/Layout.tsx(moSub 화면은 640 미만에서 메인 GNB·푸터 숨김), styles/global.css(.mo-subbar · .pc-only · .mo-only), Gnb(MO에서 "만들기"+아이콘, 로그인 버튼 숨김), 각 화면 CSS와 뒤로 링크(MO에서 Sub GNB로), 승부 예측·만들기 주 버튼을 고정 막대 안으로, 결과 버튼 고정 막대·관객은 작은 한 줄, 홈 오늘의 토론 카드 배치·목록 제목 숨김, 푸터 링크 사이 점
- 확인: 로컬 E2E(Playwright) 375×812 캡처를 Figma MO 화면(12:227, 10:96, 9:2, 11:183, 21:461)과 나란히 비교, 14항목 통과·콘솔 오류 0, PC 화면 회귀 없음 확인
- 설계 의도와 다른 점
  - 모바일 GNB에 로그인 버튼이 없다(Figma 그대로). 로그인은 [만들기]에서 모달로 하고, 로그인한 뒤에는 로그아웃 버튼이 보인다.
  - 나머지 MO 상태 화면(빈 상태·오류·시트 등)은 공통 StateBlock·Popup(바텀 시트)을 그대로 써서 따로 손대지 않았다.
