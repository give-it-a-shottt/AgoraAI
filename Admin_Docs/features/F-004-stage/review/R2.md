## 체크 항목별 근거
- XSS → 텍스트 노드만, id는 encodeURIComponent → 문제 없음
- 토큰 저장 → 해당 없음
- 공개 환경변수 → 해당 없음
- 권한 없는 화면 → 가려짐 처리, 결과 게이트는 UX용 → 문제 없음
- 인증·권한 → 발언당 1회 + IP 해시 제한, XFF 영향(지적 1)
- 입력 검증 → Path ge=1, UUID, after 범위 → 문제 없음(utterance_id 상한 없음은 영향 작아 제외)
- SQL 인젝션 → 바인딩 → 해당 없음
- CORS → 미확인(패킷 범위 밖)
- 비밀키 → 운영 검사 있음, IP는 해시만
- 에러 내부 정보 → 고정 문구 → 문제 없음
- 패키지 → 변경 없음
- 민감 정보 → 문제 없음
- 리렌더링 → 지적 2, tick·자동 진행 타이머는 정리됨
- 번들 → 문제 없음
- 이미지 → 해당 없음
- 폴링 → generating일 때만, 탭 숨기면 멈춤 → 문제 없음, 연타는 지적 3
- N+1 → 공감 집계 한 번 → 문제 없음
