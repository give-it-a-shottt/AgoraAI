## 지적
- [신규] [주의] [확실(구조)/추정(영향)] 재시도 판정이 "읽고 확인한 뒤 따로 쓰기"라 경합 틈: 동시 N개가 통과해도 retry_count는 1만 오름, 늦게 커밋된 요청이 다시 paused된 토론을 대기 없이 generating으로 되돌리고 lock_until=None으로 돌던 작업 잠금을 지움 — generation.retry, stage.retry — 코드만, 경합 재현 안 함 — 조건부 UPDATE 한 번(status=paused, retry_count<MAX, paused_at 경과)으로 묶고 rowcount 0이면 원인 판별
- [신규] [주의] [추정] Q-005 임시 처리와 관련. 작업이 AI 호출 도중 죽으면 실패 기록·잠금 해제가 없고, 180초 뒤 needs_kick이 fail_count·retry_count 증가 없이 다시 깨움 → 같은 지점에서 계속 끊기면 180초마다 호출이 끝없이 — needs_kick, _try_lock, run_next_step — 코드만, 배포 환경 동작 미확인 — 만료된 잠금을 가져올 때 fail_count += 1(3번이면 paused)
- [신규] [제안] [추정] 반각 꺾쇠만 치환 → 처음부터 전각 ＜/주제＞나 〈〉﹤﹥‹› 입력은 치환 결과와 같은 모양으로 남음(위험 낮음, 출력 검사 있음) — prompts.sanitize — 실제 모델 미시험 — NFKC 정규화 후 꺾쇠류 처리, 또는 F-007 입력에서 꺾쇠류 거절
