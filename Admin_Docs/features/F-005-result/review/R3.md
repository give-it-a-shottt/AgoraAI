- [주의] [추정] 마지막(4번째) 판정 중 프로세스가 죽으면 pending·attempts=4로 영구히 남고 재기동·다시 요청 모두 막혀 "판정 준비 중"이 끝없이 — judging._try_lock·needs_judging, routers — 해당 상태로 GET·POST 호출하면 확실 — 조회 쪽에서 pending+상한+잠금 만료면 failed로 확정
- [제안] [확실] 다시 요청 409·410 실패 시 캐시 갱신 없음, judge_limit이어도 버튼 남음 — catch에서 invalidate, judge_limit이면 버튼 숨김

## 체크 항목별 근거
- 로딩 → 스켈레톤 aria-busy 양호
- 에러 → 데이터 없을 때만 LoadError, 테스트 없음
- 상태 분기 → 모두 처리, 테스트 대부분 있음
- 네트워크 → 대체 문구 있음(client.ts 미열람)
- 입력 오류 → softDisabled + message 토스트, 선택값 유지는 제안
- 응답 코드 → 규약대로, 일부만 테스트
- 롤백 → 판정·신고 양호, 상한 중 사망만 지적 2
- 제약 위반 → 신고 중복은 기존 신고로 200
- 외부 API → 모든 예외 failed, 시도 상한·잠금 TTL, 재실패 안내는 지적 1
- 테스트 존재·정상·예외 → 있음, 공백은 제안
- 통과 → 패킷 결과
