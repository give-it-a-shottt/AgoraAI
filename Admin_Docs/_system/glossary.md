# 용어집 (일반인 말로)

| 용어 | 풀이 |
|---|---|
| API | 화면(프론트)이 서버에 "이거 줘/이거 저장해" 하고 보내는 요청 창구 |
| 공급자(provider) | 실제로 글을 써 주는 AI 회사의 창구. HyperCLOVA X, Gemini, Groq. 키가 없으면 가짜(mock) 공급자가 대신 씀 |
| mock | 진짜 AI를 부르지 않고 정해진 규칙으로 흉내 내는 가짜. 키 없이 개발·테스트하려고 씀 |
| 생성 잠금 | 같은 토론의 다음 발언을 두 군데서 동시에 만들지 않게 거는 자물쇠 |
| 발언 순번(seq) | 토론 안에서 발언의 번호(1~6). 같은 번호가 두 번 저장되지 않게 DB가 막음 |
| browser_id | 로그인 없이 "같은 브라우저"를 알아보려고 브라우저에 저장하는 무작위 번호 |
| 반박률·동의율 | 발언 중 앞 발언에 제대로 맞선 비율 / 그냥 맞장구친 비율 |
| OG 태그 | 카카오톡 등에 링크를 붙였을 때 뜨는 미리보기(제목·이미지) 정보 |
| 마이그레이션 | DB 표 구조를 바꾸는 기록. 순서대로 적용해 어느 컴퓨터에서나 같은 표를 만듦 |
| 세션 쿠키 | 로그인한 사람을 기억하려고 서버가 서명해서 브라우저에 맡기는 작은 표 |
| Cron | 정해진 시간마다 서버를 자동으로 부르는 예약 기능(오늘의 토론 하루 1회 생성) |
